# Blueprint Program Library — for review

**How it works for the client:** pick **Goal** + **Days/week** + **Location** → gets the matching program. Any exercise can be swapped if unavailable.

- **Goals** (change sets/reps/rest only): Build Strength, Build Muscle, Lean Out
- **Location:** Gym (full equipment) or Home (dumbbells + bodyweight only)

## Goal prescriptions (by exercise role)

| Role | Build Strength | Build Muscle | Lean Out |
|---|---|---|---|
| primary | 5×5 / 180s | 4×8 / 120s | 3×10 / 60s |
| secondary | 4×6 / 150s | 4×10 / 90s | 3×12 / 45s |
| accessory | 3×8 / 90s | 3×12 / 75s | 3×15 / 45s |
| isolation | 3×10 / 60s | 3×12-15 / 60s | 3×15-20 / 30s |
| core | 3×10 / 60s | 3×15 / 45s | 3×20 / 30s |
| calves | 4×10 / 60s | 4×12-15 / 45s | 3×15-20 / 30s |

_Lean Out also adds: “Finish with 8–10 min of conditioning — intervals, a circuit, or brisk incline walk.”_
